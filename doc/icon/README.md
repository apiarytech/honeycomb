# honeycomb icons

| File | Use |
|---|---|
| `honeycomb.svg` | Main logo, for light backgrounds |
| `honeycomb-dark.svg` | Same logo for dark backgrounds |
| `honeycomb-small.svg` | Simplified logo for 32 px and smaller (favicons, badges) |
| `png/` | PNG exports at fixed sizes, transparent background |
| `avatar-*.png` | 500 x 500 on white, for GitHub avatars and social previews |

In a README:

```html
<img src="doc/icon/honeycomb.svg" alt="honeycomb" width="96">
```
